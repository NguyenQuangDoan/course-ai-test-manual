# Course AI Test Manual

```
├── LICENSE
└── README.md
```

## Nội dung hiện có

- [`docs/SRS-Login-Module.md`](docs/SRS-Login-Module.md) — SRS cho module Đăng nhập, khảo sát từ hệ thống demo [crm.anhtester.com](https://crm.anhtester.com), bao gồm yêu cầu chức năng, phi chức năng, quy tắc validate, use case và các điểm cần làm rõ thêm.
